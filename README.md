# FinancialDocLab — Synthetic DataLab

This repo separates **real financial-document evaluation** from **fully fictional synthetic fine-tuning**. They must never be mixed.

## Milestone 1: 100 original hand-authored financial QA samples

**Source-of-truth:** \`sft/m1/cases/*.jsonl\` — 40 fictional case studies, each with 2–3 bespoke financial questions, evidence, worked answers and optional verifiable arithmetic. Questions, fact patterns and explanations were individually composed by the assistant, **not generated by a template loop or any external LLM API**. Code only serialized authored records and validated structure, citations and calculations.

**Ready-to-train exports (assistant role/completion):**

- \`sft/m1/exports/train.jsonl\` — 80 rows, 32 unique fictional cases.
- \`sft/m1/exports/dev.jsonl\` — 10 rows, 4 different cases.
- \`sft/m1/exports/test.jsonl\` — 10 rows, 4 different cases.

All 100 examples are new fictional company scenarios; no real company financial statement, public benchmark example, or source evidence was used to generate SFT. Each example includes complete in-context evidence, explicit evidence citations in the assistant answer, a financial interpretation, and checks where applicable.

Content balances five knowledge families (20 each), four evidence→question language pairs (25 each), and includes answerable and insufficient-evidence examples. Difficulty mix is intentional, not uniform.

## Quick start (Python standard library only)

\`\`\`bash
python -m unittest discover -s tests -v
python -m src.m1_validate --write-report
\`\`\`

A simple local baseline runner is included, but **no local LLM baseline was run in this environment**:

\`\`\`bash
# Install/start your chosen local Ollama model separately on your PC
python -m src.m1_baseline_ollama \
  --model <your-installed-model-name> \
  --dataset sft/m1/exports/test.jsonl \
  --output reports/m1_local_baseline.jsonl
\`\`\`

The baseline runner records predictions and citation presence. It **does not falsely claim to automatically judge full financial reasoning correctness**; evaluate predictions using the gold programs and manual/verified review.

Read \`sft/m1/README.md\` and \`docs/M1_REVIEW_RUBRIC.md\`.

## Real evaluation (separate PR)

External financial QA benchmarks (FinanceBench, FinQA, TAT-QA) and real PDFs belong to **eval only**. The prior work is tracked at PR #1: https://github.com/kien-test-hehe/synthetic-datalab/pull/1 . M1 is an independent branch/PR and does not depend on that code.

## What M1 does *not* establish

A 100-row hand-written seed is for review and training-pipeline proof, not a 10K SFT dataset. Formulas and source-ID integrity passed automated checks, but this is **not a complete IFRS/VAS ledger**, nor an expert-certified accounting dataset; no base-model accuracy or post-SFT improvement is claimed. Future samples must add new reasoning situations and be validated on held-out real documents.
