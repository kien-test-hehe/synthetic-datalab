# FinanceBench — noncommercial evaluation only

These three JSONL parts reproduce the **150 original published FinanceBench QA records** with source questions, original gold answers, evidence and document metadata, normalized with the explicit field `usage=EVALUATION_ONLY`. No re-generation, auto-labeling or SFT augmentation has been performed.

**Attribution**: Patronus AI, *FinanceBench: A New Benchmark for Financial Question Answering* (2023), https://arxiv.org/abs/2311.11944 ; official dataset https://huggingface.co/datasets/PatronusAI/financebench ; official repository https://github.com/patronus-ai/financebench .

Individual third-party corporate filings linked by the dataset may carry separate rights. Files here are intended for research/evaluation on a **private repository** and must not be used for model training or re-shared outside the applicable terms. Maintain `source_dataset`, `source_repository`, `license` and `evidence` fields.
